# Exercícios de PHP - Estruturas condicionais

Cada exercício pode ser executado sozinho ou em conjunto pelo arquivo executar_todos.php.
Os exercícios pedem os valores diretamente no terminal. Digite cada resposta e pressione Enter.
Use ponto para valores decimais, por exemplo: 1.75 para a altura.

## Executar no terminal PowerShell

Com o terminal aberto nesta pasta, execute todos:

```powershell
& 'C:\xampp\php\php.exe' .\executar_todos.php
```

Ou execute cada exercício separadamente:

```powershell
& 'C:\xampp\php\php.exe' .\exercicio_1\semaforo.php
& 'C:\xampp\php\php.exe' .\exercicio_2\imc.php
& 'C:\xampp\php\php.exe' .\exercicio_3\dia_semana.php
& 'C:\xampp\php\php.exe' .\exercicio_4\desconto.php
```

Se o PHP estiver no PATH, também pode usar `php .\executar_todos.php`.
Não é necessário iniciar o Apache para executar no terminal.

## Organização para entrega

O slide solicita arquivos .php e demonstra a execução pelo navegador, mas não especifica claramente se deve haver um único arquivo ou um por exercício.
Esta organização permite entregar os exercícios separados e executá-los juntos. Se incluir executar_todos.php na entrega, mantenha as quatro pastas junto dele.
Confirme com o professor se ele exige a saída no navegador, pois estes arquivos foram adaptados para o terminal conforme solicitado.

Os códigos dos exercícios mantêm a versão do autor. A calculadora de IMC pressupõe peso e altura numéricos positivos; as faixas atuais deixam lacunas entre 24,9 e 25 e entre 29,9 e 30.
